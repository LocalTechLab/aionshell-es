# Seguridad y uso responsable

AionShell ES utiliza ejecutables ya instalados para leer su ayuda y **no es un sandbox**.
Ejecuta los comandos consultados como usuario normal. El instalador solicita privilegios de administrador
para colocar archivos en `/opt` y `/usr/local/bin`; revisa el script antes de ejecutarlo.

Las comprobaciones funcionales incluidas no equivalen a una auditoría de seguridad independiente.
No publiques tokens, contraseñas, credenciales ni datos personales en issues.
Si encuentras una vulnerabilidad, utiliza la opción de informe privado de seguridad del repositorio
si está habilitada; en caso contrario, solicita un medio privado a través de los canales oficiales.
